# 月薪喵桌宠
本项目使用Codex协助完成

Windows 桌面宠物。立绘参考月薪喵图片，包含拖拽、点击动作、待机动画、定时提醒、GPT 聊天和 Codex / Work 剩余额度显示。

## 启动

Windows 用户可从[版本发布页面](https://github.com/Liurthis/yuexin-cat-desktop/releases/latest)下载便携版 ZIP，解压后运行文件夹内的 `月薪喵.exe`，无需安装 Node.js。请保留同一文件夹中的其他文件。

已安装依赖时，双击 `启动月薪喵.cmd`。首次使用可在本目录执行：

```powershell
npm install
npm start
```

想生成无需 Node.js 的便携版：

```powershell
npm run package:win
```

然后运行 `dist\月薪喵-win32-x64\月薪喵.exe`，并保留该目录内的其他文件。

如已有对应版本的 Electron ZIP，可设置 `ELECTRON_ZIP_DIR` 为 ZIP 所在目录，复用本地文件打包。

## 使用

- 拖动月薪喵来调整位置；保留原来的圆润月薪猫图片。轻点会随机播放动作库里的图片或 GIF，播放完后恢复原图。
- “设置”可调节大小（60%～180%，即时生效并记住），也可关闭自动待机动作。
- “设置 → 开机自启动”可开启或关闭 Windows 登录后自动启动。自启动只显示桌宠，不会弹出设置面板。请保留便携版所在文件夹；移动程序后重新开关一次自启动，即可更新路径。
- 窗口空白透明区域会让鼠标点击穿透到下方应用；只有可见的猫咪、气泡和工具栏接收鼠标，GIF 播放时也会更新。
- 点击、拖拽和随机播放动作时不显示动作文字；提醒事项仍会显示提醒内容。
- 猫咪右上角的独立小圆显示饱腹度：50 时填满半圈，低于 30 为红色，30 及以上为绿色。点击小圆就地展开小鱼干（+20）、小零食（+10）和猫罐头（+35），选好即可喂食；点击外部或按 Esc 收起。饱腹度初始 70，范围 0～100，每 10 分钟下降 1 点；退出后也会按经过的时间计算。吃饭期间不能重复喂食，满 100 时会停止接受食物。
- 喂食时默认播放已有的吃冰淇淋 GIF，吃完恢复原图。“设置 → 吃饭图片 / GIF”可从动作库选择、单独上传 GIF / 图片、恢复预设，以及调整吃饭时长（2～120 秒）。所选动作会保存独立副本，移除动作库中的原动作不影响吃饭图片。
- 右侧饱腹度下方的心情小圆显示心情（0～100）和表情。点开后可查看亲密等级、今日陪伴进度，并直接摸摸、逗猫或睡觉；也可以在猫咪头顶来回移动鼠标两三次摸摸它，不用按住鼠标。拖拽仍然是按住移动，轻点仍然随机播放 GIF。
- 摸摸增加 5 心情、2 亲密度（间隔 12 秒）；完成一局逗猫增加 8 心情、3 亲密度（间隔 45 秒）。点击“逗猫”后，在 12 秒内点到移动的小球三次即成功，退出或超时不会扣分。按 Esc 或点小球上方的 × 可结束。回应只显示小爱心和动作，不弹出动作文字。
- 喂小鱼干和猫罐头增加 4 心情，小零食增加 7 心情；每天有一种最爱的食物，喂它额外增加 3 心情。饭碗菜单会显示当天的喜好，喂食页会标出星星。
- 每天第一次互动、第一次完成喂食 / 摸摸 / 逗猫会增加额外亲密度；集齐三个陪伴小目标再奖励 5 心情和 5 亲密度。每日亲密度最多增加 30，亲密度不会离线减少，可从「初见」逐渐到「熟悉」「亲近」「默契」「家人」。陪伴天数按有互动的自然日累计，不要求连续签到。
- 心情每小时缓慢趋向平静：吃饱时趋向 65，饥饿时趋向 40，睡觉且吃饱时趋向 85。每小时最多变化 2 点，一次长时间离线最多计算 8 小时，亲密度始终保留。点击“睡觉”暂停随机动作、显示轻呼吸和 Zzz；点“起床”、轻点猫咪或喂食可叫醒，睡觉时提醒仍照常生效。
- “设置 → 陪伴动作 / GIF”可分别指定摸摸、逗猫成功、睡觉使用的 GIF。自动选择默认使用已有「爱你」和「喜欢」；可选择原图轻动画，也可先在动作页导入新 GIF 再指定。移除指定动作后自动回退，原来的 8 个 GIF 保持原始帧和画质。
- “动作”页可批量导入 GIF、动态 WebP、APNG、PNG 或 JPG。每个文件小于 20 MB，动作数量没有固定上限。动图保留原始帧和速度，普通图片显示为一个姿势。
- 导入后默认勾选“参与随机”。有导入动作时，从勾选的图片动作中随机选择，多个动作会避免连续重复；没有参与随机的导入动作时使用默认跳跃、摇摆和摸鱼互动。
- 每个动作可预览、手动播放、取消参与随机、调整播放时长（2～120 秒）。文件会复制到用户数据目录，删除原文件不影响使用。
- 项目附带已导入的 8 个 GIF（`assets/actions/`），首次运行会自动加入动作库。更新会保留已有动作的时长和随机播放设置；手动移除的动作不会在每次启动时重新出现。
- “设置”可开启或关闭待机随机播放、选择随机间隔（默认约 30 秒）。一个动作播放完，才开始等待下一次。拖拽或提醒会中断动作并恢复原图。
- 鼠标移到月薪喵下方，可打开提醒、聊天、动作、设置或额度页；右键也有菜单。
- 提醒支持单次和每天重复。程序需保持运行，提醒会同时显示桌宠气泡与系统通知。
- “额度”页首次使用请点“连接 ChatGPT 账户”，在浏览器中完成 Codex 登录；程序每两分钟刷新一次。这里显示 Codex / Work 用量窗口，不是 Chat 消息条数，也不是 API 账单余额。
- “聊天”使用本机 Codex App Server 和当前账户的额度。桌宠不会要求你在聊天框粘贴密码或 API Key。
- 关闭设置面板不会退出桌宠；可从系统托盘重新打开或退出。

提醒、桌宠位置、大小、动作库、心情、亲密度、每日陪伴和置顶设置保存在本机 Electron 的用户数据目录中。

## 开发

```powershell
npm test
node scripts/check-limits.js
```

额度读取使用官方 `account/rateLimits/read` App Server 方法。程序会从 PATH 和本机 Codex 桌面应用的安装目录自动查找 `codex.exe`。也可以在“额度 → 选择 Codex 程序”手动选择，或设置 `CODEX_CLI_PATH`。不需要为了启动桌宠手动修改系统 PATH。
